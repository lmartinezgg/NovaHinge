# NovaHinge

NovaHinge orchestrates distributed workloads across a decentralized platform, utilizing real-time processing and adaptive auto-scaling through a scalable gateway.

NovaHinge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NovaHinge.git`
2. `cd NovaHinge`
3. Install in editable mode: `pip install -e .`

## Configuration

NovaHinge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
